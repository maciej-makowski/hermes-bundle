# Skills

Tap root: one directory per skill, each with a `SKILL.md`. Hermes discovers them with
`hermes skills tap add maciej-makowski/hermes-bundle`, then
`hermes skills install maciej-makowski/hermes-bundle/skills/<name> --yes`.

Only skills that pass `scripts/scrub-check.sh` belong here: no hostnames, internal
addresses, personal email or handles, health data, or private repository names.
